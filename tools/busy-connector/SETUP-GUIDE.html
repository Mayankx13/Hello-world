BUSY → LIQO — Inventory Sync Setup Guide

For the store's IT / BUSY administrator. Sets up automatic hourly sync of live stock from BUSY into the LIQO app.
Estimated time: ~15 min now (discovery) + ~15 min later (final setup & scheduling). No software to install.

What this does & how it works

A small script runs on a Windows PC that can reach your BUSY SQL Server. On a timer it reads current stock from BUSY and securely sends it to LIQO over the internet, which refreshes the app's inventory. Nothing is installed (it uses Windows' built-in components), and it only makes an outgoing connection — so no firewall, router, or port changes are needed.

Windows Task Scheduler (every 30–60 min)
   -> reads stock from BUSY's SQL Server
   -> sends it over HTTPS to LIQO
   -> the LIQO app shows live, in-stock products

Before you start — you'll need

  • A Windows PC that can reach the BUSY SQL Server (the BUSY server itself is easiest).
  • Windows PowerShell 5.1+ — already built into Windows.
  • The BUSY SQL Server login (server name + username + password) — provided with this guide.
  • The LIQO access token (ADMIN_TOKEN) — provided by your LIQO admin.
  • The connector files (the busy-connector folder) — provided with this guide.
  • Normal internet access on that PC (outgoing HTTPS).
Phase 1 · Do this now — Discovery (~15 min)

This step finds where BUSY keeps its stock data and produces one file to send back to LIQO. LIQO then returns a ready-made settings file, so you don't have to know BUSY's database internals.

  1. Copy the connector folder onto the PC. Put it at C:\LIQO\busy-connector\. It should contain busy-liqo-sync.ps1, config.example.json, this guide, and a README.
  2. Create your settings file. In that folder, make a copy of config.example.json and name the copy config.json. Open config.json in Notepad.
  3. Fill in the login details. Set the values below (leave database empty for now). The password stays only in this local file. 
    "adminToken": "<the LIQO token you were given>",
"mode": "sql",
"sql": {
  "server":   "WIN-0A5I5MNR100",
  "database": "",
  "auth":     "sql",
  "user":     "SA",
  "password": "<the SQL password you were given>",
  "query":    ""
}
  4. Open PowerShell in the folder. Click the Start menu, type PowerShell, open it, then run: 
    cd C:\LIQO\busy-connector
  5. Run discovery: 
    powershell -ExecutionPolicy Bypass -File .\busy-liqo-sync.ps1 -Config .\config.json -Discover
    It creates a file called discovery-output.txt listing the databases on the server.
  6. Pick the BUSY company database. Open discovery-output.txt, look under ### DATABASES, and find your BUSY company database (ignore master, model, msdb, tempdb). Put its name into config.json → "database".
  7. Run discovery again (same command as step 5). Now discovery-output.txt also lists the tables, columns, and a data sample.
  8. Send discovery-output.txt back to LIQO. That's all that's needed to build your exact settings.
If step 5 shows a connection error BUSY may use a named database instance. In config.json, try "server": "WIN-0A5I5MNR100\\SQLEXPRESS" or "WIN-0A5I5MNR100\\BUSY" (note the double backslash) and run again. The error text will confirm the right name.
➊ What to send back to LIQO after Phase 1 The file discovery-output.txt (from C:\LIQO\busy-connector\). Do not send config.json — it has the password.
Phase 2 · After LIQO sends your ready-made settings (~15 min)

LIQO returns a completed config.json (with the stock query and column mapping filled in). Then finish setup:

  1. Replace config.json with the one LIQO sends you (keep it in the same folder).
  2. Switch to a read-only database login (recommended — don't run the daily job as SA). Open SQL Server Management Studio, connect as SA, and run (choose your own password, and use your BUSY database name): 
    CREATE LOGIN liqo_ro WITH PASSWORD = 'a-strong-password';
USE [YOUR_BUSY_COMPANY_DB];
CREATE USER liqo_ro FOR LOGIN liqo_ro;
ALTER ROLE db_datareader ADD MEMBER liqo_ro;
    Then in config.json set "user": "liqo_ro" and the new password.
  3. Do a test run (without -Discover): 
    powershell -ExecutionPolicy Bypass -File .\busy-liqo-sync.ps1 -Config .\config.json
    Success looks like: PUSH ok -> raw=… written=…. Any problem is written to busy-liqo-sync.log in the same folder.
  4. Confirm in the LIQO app. Tell your LIQO admin — they'll see the sync in the app's Activity log and the live product counts update.
  5. Ask LIQO to enable "push mode" (a one-time switch on their side) so their hourly job stops using sample data and lets your live push own the inventory.
  6. Schedule it to run automatically. Open Task Scheduler → Create Task (not "Basic Task"):
    • General: name it LIQO BUSY Sync; choose "Run whether user is logged on or not"; tick "Run with highest privileges".
    • Triggers → New: Daily; then tick "Repeat task every 30 minutes for a duration of 1 day".
    • Actions → New → "Start a program":
      Program/script: powershell.exe
      Add arguments: -ExecutionPolicy Bypass -File "C:\LIQO\busy-connector\busy-liqo-sync.ps1" -Config "C:\LIQO\busy-connector\config.json"
      Start in: C:\LIQO\busy-connector
    • Settings: tick "If the task fails, restart every 5 minutes, up to 3 times".
    Click OK and enter the Windows account password when asked. Done — stock now syncs on its own.

Troubleshooting

Message / symptomFix
Connection / login failedCheck the server name (try WIN-0A5I5MNR100\SQLEXPRESS or \BUSY), the username/password, and that this PC can reach the SQL Server.
no mappable rowsThe column names in config.json don't match the query output. This is fixed in the settings LIQO sends you — re-run with their file.
401 on pushWrong or expired LIQO token, or LIQO hasn't deployed the receiving endpoint yet. Confirm both with your LIQO admin.
Script won't run ("not digitally signed")Always launch it with -ExecutionPolicy Bypass as shown — no system change needed.
Where are the logs?busy-liqo-sync.log in the connector folder — every run is recorded there.
Security & privacy config.json (token + password) stays only on this PC and is never shared or committed. Only stock information (product code, price, quantity, brand, category, store) is sent — no customer data ever leaves the machine. Use the read-only liqo_ro login for the scheduled job.
Please don't …email config.json, screenshot the password, or paste credentials into chat/tickets. If the LIQO token needs changing, your LIQO admin will issue a new one.
➋ Questions or stuck? Send your LIQO admin the file busy-liqo-sync.log and a note of which step you're on. That's enough to diagnose almost anything.
