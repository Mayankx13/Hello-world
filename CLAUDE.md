# CLAUDE.md

## Repository Overview

This is **Hello-world**, a personal introductory GitHub repository by Mayank. It serves as a starting point and profile landing page on GitHub.

## Structure

```
.
├── README.md       # Project description and personal introduction
└── CLAUDE.md       # This file — guidance for AI assistants
```

The repository is minimal — a single `README.md` at the root with no build system, dependencies, or application code.

## Branch Conventions

- **master** — default/main branch
- Feature branches are created off `master` for changes and merged via pull requests.

## Development Workflow

1. Create a feature branch from `master`.
2. Make changes and commit with clear, descriptive messages.
3. Open a pull request to merge back into `master`.

## Conventions

- No build tools, linters, or test frameworks are configured.
- No CI/CD pipeline is in place.
- Commits should have concise, meaningful messages.

## Notes for AI Assistants

- This is a lightweight, personal repository — keep changes simple and minimal.
- Do not introduce unnecessary tooling, dependencies, or complex configurations.
- When adding files, prefer flat structure at the repository root unless there is a clear reason for subdirectories.
