# Weekly review — Sunday evening

Run via `journal weekly`. Target: 15 minutes. The shape below is a guide; honest is more important
than complete.

## 1. Roadmap pulse (3 min)

- For each domain (Body, PerfectGhar, Career, Finance, Social, Growth):
  - Active phase still active? Or should I move to the next?
  - One milestone hit this week? Mark its DOD.
  - One milestone overdue? Why? Move it or kill it — don't let it rot.

## 2. Drift check (3 min)

- Any domain with zero meaningful action this week?
- Any pattern of avoidance (same word in evening "Avoided" 3+ times)?
- Sleep / energy trend: 7-day average up, flat, or down?

## 3. Last week — wins, friction, lessons (4 min)

- Top 3 wins
- Top 3 friction sources
- One lesson worth keeping

## 4. Next week — commitments (3 min)

- One commitment per active domain (not six)
- Calendar-blocked: yes / no for each
- Dependency surfaces: anything I'm waiting on?

## 5. Honesty pass (2 min)

- What did I lie to myself about this week?
- What's the one thing I'm avoiding because it's hard, not because it's not important?
